# Verktøy og Utstyr
De fleste verktøy regnes som improviserte våpen når de brukes i kamp, men spillederen kan avgjøre at tunge eller skarpe verktøy (for eksempel brekkjern og sigder) regnes som håndvåpen. Mange av de enkelte verktøyene som er listet her, inngår i pakker med håndverksverktøy og verksteder, og trenger derfor ikke kjøpes separat.
