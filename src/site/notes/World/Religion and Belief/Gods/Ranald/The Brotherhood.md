# Broderskapet
Også kjent som _Myntgiverne_. Broderskapet er en hemmelig kabel av handelsmenn som dyrker Ranald som _Beskytteren_ og holder dette skjult. De arbeider for å avlede penger fra grådige kjøpmenn til de som trenger beskyttelse mot de mektige. I denne prosessen er svik, bedrag eller underfundige forhandlinger akseptable, så lenge ofrene ikke selv er fattige.
