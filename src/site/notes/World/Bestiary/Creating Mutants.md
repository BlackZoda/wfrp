Home: [[World/Bestiary/Mutants in the Empire\|Mutants in the Empire]]

A basic profile for creating mutants can be found on page 333 of Warhammer Fantasy Roleplay. One mutation is usually enough, but you can add more if desired. However, it is rare for a mutant to have more than four mutations, as after this point the weight of corruption becomes overwhelming.
