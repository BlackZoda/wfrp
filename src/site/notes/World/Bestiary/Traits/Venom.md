# Venom (Difficulty)
The creature’s attacks are poisoned or envenomed. When it causes [[Rules/Attributes/Wounds (W)\|Wounds]], its opponent gains a [[Rules/Conditions/Poisoned\|Poisoned]] [[0_GM/GM Screen/Sections/Condition\|Condition]]. If no [[Rules/Tests/Difficulty\|Difficulty]] is marked to resist the [[World/Bestiary/Traits/Venom\|Venom]], it is assumed to be [[Challenging\|Challenging]].
