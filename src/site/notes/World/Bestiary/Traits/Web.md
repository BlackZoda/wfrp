# Web (Rating)
The creature can create webbing to trap unwary foes. Whenever it successfully hits, opponents gain 1 [[Rules/Conditions/Entangled\|Entangled]] [[0_GM/GM Screen/Sections/Condition\|Condition]], with a [[Strenght\|Strenght]] of the *Rating* given.
