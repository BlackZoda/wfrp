# Size Combat Modifiers
If larger:
* Its weapons gain the [[Rules/Trappings/Weapons/Quaity/Damaging\|Damaging]] [[Rules/Trappings/Weapons/Weapon Quality/Weapon Quality\|Weapon Quality]] if the creature is one step larger, and [[Rules/Trappings/Weapons/Quaity/Impact\|Impact]] [[Rules/Trappings/Weapons/Weapon Quality/Weapon Quality\|Weapon Quality]] of two steps or more larger.
* It multiplies any [[Rules/Injuries/Damage\|Damage]] caused by the number of steps larger it is (so, 2 steps = x3, 3 steps = x3, and so on); this multiplication is calculated after all modifiers are applied.
* All successful strikes agaist smaller targets activate the [[Rules/Combat/Deathblow\|Deathblow]] rule, even if the target survives
If smaller:
* It gains a bonus of +10 to hit.
