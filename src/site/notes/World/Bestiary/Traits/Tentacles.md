# \# Tentacles (Rating)
The creature has a number of tentacles equal to #. It gains one [[Rules/Combat/Attacking\|Free Attack]] [[Rules/Combat/Action\|Action]] per tentacle. Each tentacle’s attack does *Rating* [[Rules/Injuries/Damage\|Damage]], *which includes its [[Strenght\|Strenght]] [[Rules/Attributes/Characteristic Bonus\|Bonus]] already*. If it causes [[Rules/Injuries/Damage\|Damage]], it can also give its opponent an [[Rules/Conditions/Entangled\|Entangled]] [[0_GM/GM Screen/Sections/Condition\|Condition]], which will initiate a [[Rules/Combat/Grappeling\|Grapple]] between the target and that tentacle. If a tentacle is [[Rules/Combat/Grappeling\|Grappeling]], use the tentacle’s [[Rules/Combat/Attacking\|Free Attack]] [[Rules/Combat/Action\|Action]] to resolve that [[Rules/Combat/Grappeling\|Grapple]], not the creature’s [[Rules/Combat/Action\|Action]].
