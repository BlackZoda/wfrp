# Opposed Strength
During **[[Rules/Tests/Opposed Test\|Opposed]] [[Rules/Attributes/Strength (S)\|Strength]]** [[Rules/Tests/Tests\|Tests]] (and similar), if one creature is 2 or more size steps larger, it wins automatically. If one creature is 1 size step larger, the smaller creature must roll a [[Rules/Tables/Critical Tables\|Critical]] to contest the roll. If it does, [[Rules/Tests/Success Levels\|SL]] are compared as normal. All other results mean the larger creature wins.
