| 1d10 | Result                                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1–2  | **Snapped Harness:** One horse (or equivalent) breaks free; reduce speed accordingly.                                           |
| 3–5  | **Jolted Carriage:** Passenger suffer 1 Wound and fragile cargos might be damaged.                                              |
| 6–8  | **Broken Wheel:** Pass a Drive Test every round to avoid Crashing. Two-wheeled vehicle with a Broken Wheel Crash automatically. |
| 9–10 | **Broken Axle:** The vehicle goes out of control and Crashes.                                                                                                                                |
