Lock Difficulty ratings assume the use of lock picks. Improvised picks such as hairpins and nails can be used at a *-10 penalty*. Each [[Rules/Tests/Tests\|Tests]] normally takes a [[Rules/Combat/Round\|Round]] to complete, though the GM may determine some locks are particularily stiff or rusted, and take longer. If the GM deems a lock is sufficiently simple, unskilled characters can attempt a single **Very Hard (-30) Dexterity** Test to pick the lock. The following provides some standard difficulties for locks typically encountered in the Old World.

| Lock Type      | Difficulty       | SL  |
| -------------- | ---------------- | --- |
| Latch          | Average (+20)    | 0   |
| Normal Door    | Challenging (+0) | 2   |
| Secure Door    | Difficult (-10)  | 2   |
| Treasure Chest | Hard (-20)       | 5   |
| Vault Door     | Very Hard (-30)  | 10  |
