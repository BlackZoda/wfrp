Any one-handed weapon with the [[Rules/Trappings/Weapons/Quaity/Defensive\|Defensive]] Quality can be used with **[[Rules/Skills/Melee\|Melee]] (Parry)**. When using **Melee (Parry)**, a weapon can be used to Oppose an incoming attack without the normal –20 offhand penalty (see page 158).
