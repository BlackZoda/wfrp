Home: [[Rules/Tests/Tests\|Tests]]

Sometimes the adventure will call for a *specific number of Success Levels* be achieved to fully succeed at a *time-consuming or especially taxing task*. Doing this requires a special [[Rules/Tests/Dramatic Test\|Dramatic Test]] called an **Extended Test**. Extended Tests are handled in the same fashion as any other Dramatic Test, but the *SL scored from multiple rolls are added together to reach a specified target*. If the total SL scored ever falls *below 0, you can start again from scratch* with the next roll.
