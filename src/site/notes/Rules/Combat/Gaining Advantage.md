Home: [[Rules/Combat/Advantage\|Advantage]]

* [[Rules/Combat/Surprise\|Surprise]]: Attacking [[Rules/Conditions/Surprised\|Surprised]] enemies brings **+1 Advantage**. See page 169.
* [[Rules/Combat/Charging\|Charging]]: Charging headlong into combat grants **+1 Advantage**. See page 165.
* [[Assess\|Assess]]: If you use one of your [[Rules/Skills/Skill\|Skill]]s to secure a tactical advantage, gain **+1 Advantage**. See individual Skill descriptions in **Chapter 4: [[Rules/Skills/Skill\|Skill]]s and [[Rules/Talents/Talent\|Talent]]s** for more details concerning this.
* [[Victory\|Victory]]: Whenever you defeat an important NPC, gain **+1 Advantage**. Subduing a party *nemesis* may grant **+2 Advantage**.
* [[Winning\|Winning]]: If you win an [[Rules/Tests/Opposed Test\|Opposed Test]] during combat gain **+1 Advantage**.
* [[Outmanouevre\|Outmanouevre]]: If you wound an opponent without engaging in an [[Rules/Tests/Opposed Test\|Opposed Test]], gain **+1 Advantage**.

There is also an array of [[Rules/Talents/Talent\|Talent]]s that secure Advantage. Refer to **Chapter 4: [[Rules/Skills/Skill\|Skill]]s and [[Rules/Talents/Talent\|Talent]]s** for more on this.
