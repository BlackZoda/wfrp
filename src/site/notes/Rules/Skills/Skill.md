Skills represents areas of trained learning or experience. The skills you have available to you at character generation are determined by your [[Rules/Species/Species\|Species]] and [[Rules/Career/Career\|Career]].

When you learn a Skill, note down the number of [[Rules/Attributes/Advances\|Advances]] you gain in the Advances box of the [[Rules/Skills/Skill\|Skill]]. If you should learn this skill again, add the extra [[Rules/Attributes/Advances\|Advances]] to the old total to create a new number of [[Rules/Attributes/Advances\|Advances]].

Skills are classified as either *Basic* or *Advanced*. [[Basic Skills\|Basic Skills]] represent common abilities that everone can perform – you can use these skills without any [[Rules/Attributes/Advances\|Advances]] in them, at a leval equal to the governing characteristic. [[Advanced Skills\|Advanced Skills]] require specialist knowledge, and you can only use these skills if you have taken at least one [[Advance\|Advance]] in them.
