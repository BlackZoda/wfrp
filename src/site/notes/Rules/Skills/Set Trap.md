**(Dex) advanced**

From a simple snare, or bear-trap, to more spectacular devices like [[Von Grizzel’s Thief-Render\|Von Grizzel’s Thief-Render]], players are unlikely to venture far in [[World/Other Nations/Den Gamle Verden\|Den Gamle Verden]] without enountering traps. The Set Trap [[Rules/Skills/Skill\|Skill]] measurs your ability to set and disarm traps of all varieties. Anyone with the skill is automatically assumed to ba able to activate and disarm traps given enough time. A Test is normally only required if attempting to use the Skill swiftly or if otherwise under pressure, or if the trap is especially complex. A selection of simple traps can be found in the [[0_GM/GM Screen/Sections/Consumers’ Guide\|Consumers’ Guide]].

Setting or disarming most traps requires an **Average (+20%) Set Trap** Test, but more complex devices may require an [[Rules/Tests/Extended Test\|Extended Test]], needing several SL over multiple rounds to set.
